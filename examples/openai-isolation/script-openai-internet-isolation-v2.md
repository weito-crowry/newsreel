- 画面: レッドチーミング図解（攻めるAIエージェント群 vs 守る境界・盾、段階表示）。見出しテロップ「最強モデルで「脱出実験」」
- 出典クレジット: 出典: OpenAI公式ブログ
- ナレーション:
  1. 注目すべきは、対策のやり方です。
  2. 自社の最強モデルを「脱出役」にした大規模なレッドチーミングを行い、未知の脆弱性や設定ミスを洗い出して塞ぎました。
  3. オープンソース側の問題は、Patch the Planetという取り組みで、開発者と連携して修正しています。
  4. 対策を終えて、学習は10月1日に再開されました。
